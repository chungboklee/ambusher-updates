# Ambusher Updates

This public repository contains only signed update metadata and notarized
download artifacts for Ambusher.

- Source code is kept in the private `chungboklee/ambusher` repository.
- `appcast.xml` is consumed by Sparkle.
- `current.json` describes the current ZIP and DMG with SHA-256 hashes.
- Download files are immutable GitHub Release assets.

No source code, Apple credentials, GitHub tokens, or private signing keys belong
in this repository.
